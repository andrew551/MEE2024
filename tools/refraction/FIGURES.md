# Figures: what produced what, and how to regenerate

Every figure in `docs/figures/` is regenerated by one script here. All read reductions
under `D:\MEE2024 output\MEE_output\refraction\` and raw frames on `G:\Leon Aug 2026`;
none needs a telescope-data re-reduction. Run with the venv:

```bash
.venv/Scripts/python.exe tools/refraction/<script>.py
```

| figure | script | what it shows | status |
|---|---|---|---|
| `stability_vs_tube_temperature.png` | `tube_temperature_chart.py` | **the campaign's summary figure** — plate scale and free-cubic d(3000) against normalised tube temperature (FOCTEMP − 7.74 K), night 1 shown but unfitted | **current** |
| `m4_curves.png` | `m4_analysis.py` | the meridian mosaic: corrections-ON scale vs altitude (the model-validity curve), plus rms and star count | **current** |
| `m3_quiver_maps.png` | `m3_maps.py` | nine quasi-static residual maps — the wavefield, arrows in arcsec | **current** |
| `m3_vertical_profiles.png` | `m3_maps.py` | vertical residual vs altitude within frame — oscillatory, not polynomial | **current** |
| `platescale_vs_temperature.png` | `final_charts.py` | plate scale against both thermometers side by side | current (superseded as the *summary* figure by `stability_vs_tube_temperature.png`) |
| `cubic_vs_temperature.png` | `final_charts.py` | cubic against both thermometers | as above |
| `night2_temperature.png` (**not versioned**) | `night2_temperature.py` | first attempt at the temperature story | **SUPERSEDED** — its cubic panel has a time-wrap bug putting band points at ~29 °C (§16.1). Do not reuse; the script is kept only for provenance. |

## The two flagged for publication / collaborator use

**`stability_vs_tube_temperature.png`** — two stacked panels on one physically meaningful
axis. The construction (Douglas', §16.5): the FOCTEMP sensor is mechanically coupled to
the telescope so it supplies the *dynamics*; the calibrated free-air logger supplies the
*scale*, through the measured +7.74 ± 0.67 K offset. If regenerating for publication, the
offset is set at the top of the script (`OFF = 7.74`) and the reference plate scale at
`REF`. Caption facts: plate-scale fit −109.2 ± 4.7 ppm/K at r = −0.95 (n = 55, unflipped
night-2 fields); this is an **empirical FOCTEMP-referenced slope** — the physical coupling
is bracketed −16 to −40 ppm/K (§16.9–16.11), so do not quote −109 as a material property.

**`m4_curves.png`** — 78 of 80 mosaic fields. Caption facts: the standard refraction model
holds to ≲50 ppm above alt 10° once drift (+1.4 ppm/min), north–south asymmetry
(−56 ± 14 ppm) and the pier flip are removed; below 10° the residuals reach the ±900 ppm
class and the plate solver itself fails between alt 5.0° and 5.6°. The eclipse was at 9.6°.

## Analysis scripts that produce tables rather than figures

| script | produces |
|---|---|
| `three_estimators.py <dir> [nx ny]` | HC0 / HC3 / jackknife for any set of stage-2 runs (sensor size matters: 6248 4176 for the ASI2600, 3326 2504 for Bruns' ML8051) |
| `m2_synthesis.py` | the nine horizon field-windows: slopes, offsets, differentials |
| `band_stability.py` | mosaic stability band: plate scale and free-cubic d(3000) |
| `night1_cal_temperature.py` | night-1 and CAL_piLeo temperature decompositions |
| `coma_nights.py` | radial FWHM growth and the tilt dipole, night vs night |
| `sky_gradient.py` | the totality sky gradient and its centroid-bias pricing |
| `cal_variants.py` | CAL_piLeo frame-selection variants |
| `checkpoint1_slopes.py`, `checkpoint2_all_fields.py` | intermediate M2 checkpoints (superseded by `m2_synthesis.py`) |

One import note: `band_stability.py` runs its analysis at module level, so importing it
(as `tube_temperature_chart.py` and others do, for `d3000`) prints that analysis as a side
effect. Harmless, but it is why those scripts' output needs filtering.
